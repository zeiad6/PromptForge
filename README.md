# 🔥 PromptForge — برومبت فورج

<div dir="rtl">

**استوديو هندسة الأوامر الاحترافي — من هاتفك بالكامل، بلا حاسوب.**

تطبيق أندرويد مفتوح المصدر (للاستخدام الشخصي) لبناء وتحسين وتنفيذ الأوامر (Prompts) مع 6 مزودين سحابيين + **ذكاء اصطناعي يعمل داخل الهاتف بالكامل دون إنترنت**.

</div>

**A professional prompt-engineering studio — entirely from your phone.**
An open-source (personal-use) Android app to build, enhance and execute AI prompts with 6 cloud providers + **fully on-device LLMs that work offline**.

---

<div dir="rtl">

## ✨ المميزات

| | |
|---|---|
| 🧠 **ذكاء على الجهاز** | شغّل موديلات LLM داخل هاتفك عبر Google AI Edge — بلا حاسوب وبلا إنترنت، مع استجابة متدفقة |
| 🛒 **متجر موديلات مدمج** | تنزيل بنقرة واحدة (SmolLM2 135M / OLMo 2 1B / Qwen2.5 1.5B) مع **إشعار تقدم في شريط الحالة واستكمال تلقائي وعمل في الخلفية** |
| ☁️ **6 مزودين سحابيين** | Gemini · Groq · OpenRouter · Mistral · Cerebras · Ollama (شبكة محلية) |
| ✍️ **بانٍ احترافي** | تعزيز بالذكاء الاصطناعي، وضع البحث مع توثيق المصادر، **تعزيز الإبداع** بتوجيهات حِرفية احترافية، توجيهات بلا قيود، أقسام مخصصة غير محدودة |
| 🎚️ **تحكم كامل بالإبداع** | من «دقيق» إلى «جامح» بمدرّجة حرارة حتى 1.5 ووصف حي لكل مستوى |
| 🧪 **المختبر** | محادثة حية مع أي موديل، تدفق حرفاً بحرف، تحرير وإعادة إرسال، تجديد الرد |
| 📚 **مكتبة وقوالب** | قوالب جاهزة، حفظ وتقييم فوري لجودة كل أمر مع اقتراحات تحسين |
| 🌍 **ثنائي اللغة** | عربي/إنجليزي كامل مع تبديل فوري وكشف لغة النظام |
| 🛡️ **خصوصية أولاً** | بلا حسابات، بلا تتبع، بلا تحليلات — مفاتيحك تبقى في جهازك |

## 📲 التثبيت

حمّل أحدث APK من صفحة [Releases](../../releases) وثبّته مباشرة (فعّل «التثبيت من مصادر غير معروفة»).

## 🧠 الموديلات على الجهاز

1. الإعدادات ← «على الجهاز» ← اختر موديلاً من **المتجر المدمج** ونزّله بنقرة واحدة
2. بعد اكتمال التنزيل يُفعَّل تلقائياً — ثم كل شيء يعمل أوفلاين
3. موديلات Google Gemma تتطلب قبول الترخيص في متصفحك أولاً (روابطها مرفقة داخل التطبيق)

## 🛠️ البناء من المصدر

</div>

```bash
# Requirements: JDK 17, Android SDK (compileSdk 36), Gradle 8.x
git clone https://github.com/OWNER/PromptForge.git
cd PromptForge
echo "sdk.dir=/path/to/android-sdk" > local.properties
./gradlew :app:assembleRelease   # or: gradle :app:assembleRelease
# APK → app/build/outputs/apk/release/
```
